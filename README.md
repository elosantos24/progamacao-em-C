# 💻 Estudos de Programação em C

Bem-vindo ao meu repositório de **estudos e práticas de programação em Linguagem C**.

Este espaço foi criado com o objetivo de **registrar e organizar os códigos desenvolvidos durante as aulas**, acompanhando minha evolução no aprendizado dos fundamentos da programação.

## 🎯 Objetivo

Utilizar este repositório como um **diário prático de aprendizagem**, onde serão publicados os exercícios, exemplos e atividades desenvolvidos ao longo das aulas de programação em C.

A ideia é manter os códigos organizados e documentados para acompanhar minha evolução, revisar os conteúdos estudados e construir uma base sólida em programação.

## 🧠 Aprendizado

Mais do que apenas armazenar códigos, este repositório representa meu processo de **aprendizado, prática e evolução na programação**.

Os códigos aqui apresentados fazem parte das atividades realizadas durante as aulas e serão utilizados para colocar em prática os conceitos aprendidos em sala.

> **Programar é transformar lógica em solução.**

## 🚀 Evolução

Este repositório estará em constante atualização conforme novas aulas, exercícios e desafios forem realizados.

A cada novo código publicado, o objetivo é registrar mais uma etapa da minha evolução na Linguagem C e no desenvolvimento do raciocínio lógico.
